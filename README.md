# Aplicação Flask
Aplicação desenvolvida em Flask durante a Formação Python da OneBitCode, com foco em aprendizado prático de desenvolvimento web.

## Objetivo
Explorar os principais conceitos do Flask, como rotas, organização do projeto em pastas, integração com banco de dados, além do uso de HTML e CSS.  
O projeto foi versionado no GitHub e integrado ao Render para fins de deploy da aplicação.

## Descrição
A aplicação é composta pelos seguintes módulos:
- **Home**: exibe e adiciona uma lista de conteúdos.
- **Diário**: permite cadastrar o nome do aluno e sua respectiva nota, armazenando os dados.
- **Filmes**: lista filmes populares, animações e filmes de 2010, com descrição e imagem.
- **Livros**: funcionalidade de CRUD completo (adicionar, editar e excluir), com listagem paginada.

## Como usar
1. Clone o repositório ou baixe os arquivos do projeto.
2. Crie e ative um ambiente virtual.
3. Instale as dependências listadas no arquivo `requirements.txt`.
4. Execute a aplicação no terminal com o comando:
```bash
flask --app projeto run --debug
